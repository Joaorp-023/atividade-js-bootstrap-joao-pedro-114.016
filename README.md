
# Painel de Notas

## Tema
Painel de notas de um aluno.

## Interface
A interface mostra duas notas e a media do aluno.
Tambem mostra se o aluno foi aprovado.

## Bootstrap
Utilizei navbar, container, row, col, card, badge,
button, alert e footer para organizar a pagina.

## Variaveis
const: utilizada para valores que nao precisam mudar.
let: utilizada para valores que podem ser alterados.
var: forma antiga de declarar variaveis.

## Tipos de dados
string: textos.
number: numeros.
boolean: verdadeiro ou falso.
null: valor vazio ou ausente.

## Condicao if/else
O if verifica se a media e maior ou igual a 7.
Se for, o aluno esta aprovado.
Caso contrario, esta reprovado.
